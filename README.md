# 📄 Footer Component

Komponen **`Footer.js`** ini merupakan bagian dari struktur layout frontend yang digunakan untuk menampilkan informasi footer di bagian bawah halaman website.  
Komponen ini mudah digunakan, responsif, dan dapat disesuaikan sesuai kebutuhan proyek Anda.

---

## 📁 Struktur File

components/
│── Footer.js

---

🧪 Catatan Pengembangan
Komponen ini bersifat reusable dan dapat digunakan di berbagai halaman.
Dapat dikustomisasi dengan menambahkan class Tailwind atau CSS sendiri.
Pastikan file ini berada di folder components proyek Anda.

---

📜 Lisensi
Silakan gunakan, ubah, dan distribusikan dengan bebas.
